# 幻想乡 · 一生纪

东方Project同人人生模拟器，版本 **23.1.0**（交付修订2）。从十份天赋中选三份、分配20点属性并选择心愿，随后自动推进人生。支持暂停、继续、速度切换、结算、特色PNG导出和重开，适配电脑与手机。

## 直接游玩

`site/` 已包含完整静态网页，不必先安装Node依赖：

```sh
python3 -m http.server 8080 --directory site
```

Windows也可使用 `py -m http.server 8080 --directory site`。浏览器打开 `http://localhost:8080`。

游戏无需后端、账号或付费API。核心游戏可离线运行；外部背景音乐需要联网，也可选择本机音频。当前人生保存在页面内存，刷新会结束本局。

## 内容

- 普通人开局95%，具名人物开局合计5%：正作及官方出版物3.75%、秘封0.875%、旧作0.375%。先抽类别再抽人物。
- 185种具名身份、1323条带来源的前史、6660条人物随机事件；185人的连续来往中，165人有独立情缘。
- 职业、修行、迁居、伤病与机缘按状态推进，长寿角色有自己的时间尺度。目标与结局由实际经历判定。
- 四条少年篇属于明确标注的二创；具名成人亲密、婚事与村民路线分别保留自己的年龄条件。一生只确立一位恋人。
- V21至V23增加高级天赋、长寿生活、神灵发展、神明来往和伴侣后续。
- V23.1为18类多年日常补入72条后续，修整梦子、米斯蒂娅、赫卡提亚及穰子、雏的相关正文；按原典补正神灵以人形相见的描写。该修订沿用V23的概率、年龄、寿命、信仰及关系机制。

人物原作背景和同人续篇分开标注。作品、人物来源和收录边界见游戏内“作品与来源”、`docs/roster-research.md` 与 `data/chronicles/`。

## 构建与验证

需Node.js 20+，依赖版本固定在锁文件：

```sh
npm ci
npm run build
npm test
```

`data/` 是全部角色、事件和关系数据；`dist/` 保留可读运行源码；`scripts/build*.mjs` 负责内容校验、生成与兼容构建；`site/` 是实际部署目录。`tests/` 保留八组公开回归及必要输入，涵盖情缘、少年篇、伴侣回顾、神灵发展和V23.1文案与机制对照；不包含私人报告或历史大批采样。V23对照基线以压缩测试输入提供，不依赖Git历史。修订2保留原V21输入及来源指纹，并以归档V23运行模块逐项比较当前非文案状态与随机数调用次数；历史覆盖结果不冒称当前覆盖。完整开发验证档案未包含在本公开仓库中。

构建会生成覆盖报告到被Git忽略的 `reports/`。运行 `npm start` 可在8080端口预览。发布时将 `site/` 中全部文件放到静态托管目录即可，HTML使用相对路径，无需账户设置或服务器密钥。

兼容产物以Chrome／Android WebView 49为语法基线，含本地运行库；这不等同于对所有旧设备的实机保证。
